# 入畫《山行》GitHub 教師加密版

解壓後，把裡面的全部檔案及資料夾上傳到教師版倉庫根目錄，覆蓋同名檔案。

首頁的「教師賞詩」會在同一個 GitHub 網站內開啟 appreciation.html。輸入設定的教師密碼後，瀏覽器會解密並開啟賞析。賞析內容和程式以 AES-GCM 加密，密碼及明文賞析內容均不包含在上傳檔案內。密碼不會傳往外部網站，也不會儲存在本機進度中。

保留開場故事、輸入杜牧姓名、尋憶遊戲、積分、讀詩圈選、四頁教師賞析、兩秒煙花、Padlet 及課後溫習連結。賞析從「你知道我最喜歡的是甚麼景物嗎？你怎麼知道的？」開始。「鎖定賞析」及重新整理均會回到密碼頁。

上傳時請包含 appreciation.html、ruhua/teacher-unlock.mjs、ruhua/teacher-lesson.enc.json，以及套件內原有的 appreciation 檔案，這些會替換前一版的跳轉頁及明文內容。

請透過 GitHub Pages 的 HTTPS 網址使用。此版由瀏覽器解密，取得密碼的人即可開啟賞析。
